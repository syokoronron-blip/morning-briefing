# morning-briefing

毎朝自動生成される「インスピレーション・ブリーフィング」のアーカイブサイトです。
GitHub Pages で公開されています。

## 構成

- `index.html` — 全日付のアーカイブ一覧（最新日にリダイレクト）
- `days/YYYY-MM-DD.html` — 日付ごとのブリーフィング本体（インスピレーション／業界ニュースの2タブ構成）
- `assets/site.css`, `assets/site.js` — 全ページ共通のスタイルとタブ切り替えスクリプト

## 更新の仕組み

毎朝、スケジュール実行されるエージェントが以下を行います。

1. 直近24〜48時間のニュースをウェブ検索で収集
2. `days/YYYY-MM-DD.html` を新規作成
3. `index.html` のアーカイブ一覧に当日分を追加（先頭に挿入、最新日にリダイレクト）
4. ブランチにpush → Pull Requestを作成 → 自動マージ
